# Font Fling ♡
*witty.fig presents…* a dating app for typefaces, in a soft little notebook.

## What's inside
- **Intro** – a dramatic, fade-in-one-page-at-a-time welcome, ending in a giant LET'S GET FLINGING! button.
- **Font Dating** – swipe (drag, buttons, or arrow keys) through 40 fonts. Each has a live specimen, a fictional personality, a first-person bio, green and red flags and a compatibility score. ✕ pass, ♥ like, ★ super-like (drag up or press ↑).
- **Compat Quiz** – five questions for lazy romantics, then three recommended fonts, why they suit you, and how they'd work as a trio. Add all three to your matches or just one.
- **Decor Bits** – an editable canvas: type, move the cursor anywhere, and tap charms to add them right where it is. Copy it or pin it to your scrapbook.

Matches, super-likes and scrapbook items are saved in your browser (localStorage).

## Files
- `index.html` – structure
- `style.css` – notebook look + animations
- `script.js` – fonts data, swiping, quiz, builder, intro

## Run it
Open `index.html`, or enable GitHub Pages (Settings → Pages → deploy from `main`, root folder).
Fonts load from Google Fonts, so you need to be online.

## Notes on fonts
- Fonts load on demand from Google Fonts as their cards come up, so the page stays fast.
- **Papyrus** is a system font, not a web font. It shows on Mac and Windows; other devices fall back to a similar decorative font.
